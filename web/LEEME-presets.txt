TONE ATLAS · PROYECTO LOCAL

ARRANCAR SIN CODEX
Abre una terminal en esta carpeta y ejecuta npm start. Se abre la web en tu navegador:
http://127.0.0.1:5178
Mantén abierta la ventana del servidor. Para detenerlo, pulsa Ctrl+C.

DESARROLLO CON RECARGA AUTOMÁTICA
Ejecuta npm run dev y abre http://127.0.0.1:5178 en el navegador.
Al guardar presets.json, HTML, CSS, JavaScript u otro archivo del proyecto, Node reinicia el servidor y la página se recarga automáticamente al reconectar (normalmente en pocos segundos).
No necesitas reiniciar el comando ni pulsar F5. Los cambios en el código del servidor también se aplican automáticamente.
En modo dev no se abre una pestaña nueva con cada reinicio: abre la dirección una vez y mantenla abierta.
No uses npm start y npm run dev al mismo tiempo: comparten el puerto 5178.
npm start conserva el funcionamiento normal, sin vigilancia ni recarga automática.
La recarga descarta cambios de formularios que aún no hayas guardado. Los ajustes personales guardados siguen teniendo prioridad sobre el catálogo; usa Usar ajustes del JSON si quieres aplicar los valores del archivo.

REQUISITOS
Windows y Node.js instalado (ya está disponible en este ordenador).
No requiere npm install, cuentas, credenciales ni Codex.
También puedes abrir una terminal en esta carpeta y ejecutar:
node server.cjs
No abras index.html con doble clic: la lectura de JSON necesita el servidor local.

AÑADIR BANDAS Y CANCIONES
1. Edita web/presets.json con tu editor de texto.
2. Copia una canción existente o la de web/presets.ejemplo.json.
3. Escribe un id único y completa artista, titulo, pastilla, notas y bloques.
4. base y solo usan los textos "ON" u "OFF". AMP y CAB siempre ON.
5. Guarda el archivo. Con npm run dev la página se recarga sola; con npm start, recarga manualmente. Aquí no necesitas publicar nada.

Para una banda nueva, añade un objeto a bandas con artista y canciones.
El orden de bloques es el orden de la cadena. Se asignan a CTRL solo los bloques que cambian de ON a OFF o viceversa. Un modelo por bloque; sus valores son fijos.
Los ajustes son instrucciones para introducir manualmente en la GE200. La app no controla la pedalera ni genera sonidos de artistas automáticamente.

VALIDAR Y PROBAR
npm run validate
npm test

DATOS GUARDADOS
Los favoritos y ajustes personales se guardan en el navegador para http://127.0.0.1:5178.
El catálogo sin personalizar sigue los cambios del JSON al recargar. Si tienes ajustes personales para una canción, pulsa Usar ajustes del JSON para aplicar la versión del archivo.
Las canciones retiradas del JSON pueden continuar en una biblioteca guardada; no se borran tus datos automáticamente.
La biblioteca de la web publicada usa otro origen y no aparece automáticamente aquí: allí pulsa Exportar biblioteca y aquí pulsa Importar.
Usa siempre la misma dirección y navegador para conservar el mismo almacenamiento. Exporta la biblioteca para hacer una copia de seguridad.

CARPETAS
web/: aplicación y presets.json, con catálogo, ejemplo y guía.
server.cjs: servidor local, solo accesible desde tu ordenador.
package.json: comandos npm start, npm run dev, npm run validate y npm test.
validate-presets.cjs: validación del catálogo sin dependencias.
tests/: pruebas de catálogo y migración.

La aplicación funciona sin conexión a Internet. Las fuentes visuales pueden usar las del sistema si Google Fonts no está disponible. El enlace al manual externo sí necesita Internet.
